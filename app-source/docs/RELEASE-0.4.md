## Native boundary

The repository now contains Capacitor configuration and a reproducible iOS setup procedure. An App Store binary cannot be truthfully marked complete until Apple signing, physical-device testing, App Store Connect metadata/privacy answers and review submission are performed with the owner's Apple Developer account.
