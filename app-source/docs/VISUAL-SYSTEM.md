# Visual Direction v2.0

Luxury Cyber Minimalism. Data is quiet; interaction creates light; important moments create depth.

Foundation: #070708; raised #0E0F11; glass #151619 with opacity; warm white #F4F2EC; gold #C5A461, highlight #E0C783, deep #77613A. Blue/violet only in Companion lighting, never primary actions.

Flat: nutrition and data. Glass: navigation and sheets. Intelligence Glass: review and recommendations. Desktop compact rail / mobile floating dock, exactly four primary routes.

Spacing scale 4, 8, 12, 16, 24, 32, 48, 64, 96. System labels 10–12px and 0.12em tracking. SF/system font with PingFang TC fallback.

Motion: tab 240ms, detail 300ms, immersive 450ms, sheet 280ms. Native View Transition where supported; normal navigation otherwise. All decorative motion disabled with prefers-reduced-motion. Three renderer uses demand rendering for reduced-motion mode. No artificial loading delay.
