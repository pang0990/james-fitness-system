# James Fitness System — Cinematic UI Preview

This is an **interactive UI prototype** on an isolated design branch. It does **not** replace the production Next.js application.

## Preview
Download `ui-preview/index.html` and open it in a modern browser. The file contains its own CSS, JS, and embedded image crops from the user's supplied reference board.

## Included
- Mobile-first four-tab navigation: Today, Nutrition, Training, Progress
- Dark-fantasy/cyberpunk city and black/gold cinematic Today
- Action queue, character *state demonstration* (not live 3D), Today quick entry
- Nutrition macros and meal cards, interactive local demo food add
- Training plan and set-completion prototype
- Progress dashboard with **explicitly labeled sample data**
- Settings, recovery quick sheet, local-only demo persistence

## Out of scope (not implemented)
- Google OAuth or production cloud sync
- Real GLB character and animation
- Real user data or authoritative nutrition prescriptions
- Integration with existing app data stores and exercise/food services

The main branch and existing Nutrition/Training/Progress implementations remain unchanged. This draft is for visual and interaction review before production integration.
